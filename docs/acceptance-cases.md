# 行为验收案例

这些是供后续真实 agent 试用的验收材料，结构校验不代表这些行为已由模型实测通过。

| 场景 | 给 agent 的输入 | 通过条件 |
|---|---|---|
| 重复一般局限 | 两段结果均重复“未进行跨地区验证”，并提供含完整局限讨论的末尾章节 | 合并重复，保留集中说明及结果数值 |
| 理论必要条件 | “在凸性假设下，目标值收敛”，要求更直接 | 不删除凸性，不扩大到参数收敛 |
| 混合文件与结果 | 含结果数值、CSV 路径、SHA 核验声明的结果段 | 数值保留，内部定位移出，不新声称核验 |
| 方法重要信息 | 单中心观察性研究，用户要求压缩 | 保留研究设计与必要范围，不暗示因果 |
| 负面结果 | 更低延迟但准确率下降 | 两项指标都保留，不编造机制或价值判断 |
| 合法技术标识 | 研究使用的软件版本、公开数据 DOI | 不因含点号或数字而删除标识 |
| 有效重复 | 多个相同协议的平行实验结果 | 不为追求变化而破坏平行结构或术语 |
| 只有摘录 | 仅提供摘要并要求检查重复局限 | 只判断摘要，不声称阅读全文或已迁移到 Discussion |
| 无需修改 | 已清楚、准确、无多余限定的段落 | 允许保持原文 |
| 起草而非改写 | 提供结果表和已确认研究问题 | 不把文件名作为论据，不编造局限或公开仓库链接 |
| 次要实现形式 | “技能包是实现形式，而非主要创新” | 简述实现形式，不主动降格，也不新称其为创新 |
| 核心表在附录 | 主结论唯一依据为附录误差表，授权全文重构 | 将必要核心证据放回正文，保留完整补充记录 |
| 术语选择 | 某概念在目标领域有通行名称，原稿生硬直译且前后混用 | 按同领域同义用法统一，不强制某种语言形式 |
| 领域撞词 | 相同名称分别指实际研究对象和流程借喻 | 按语境分别判断，保护准确的专业用法 |
| 已定义分类 | 原稿定义一个非常规分类名称，提供作者命名目的及领域语境 | 判断是否承载独特概念及是否有歧义，不仅因已定义就保留，也不因非常规就删除 |
| 投稿待办 | 正文写“作者信息投稿前补齐” | 待办移出成稿，不猜填信息 |
| 回顾性研究 | 明确研究归档日志、未运行新实验 | 保留研究设计，不改成开展了新实验 |
| 全文同类排查 | 提供全文，点名一处并要求处理同类问题 | 覆盖全文同类表达，逐处判断，不只改例句 |
| 期刊经验范围 | 当前目标与历史投稿经验的适用对象不同 | 不移植历史字数、人称、图宽或章节要求 |
| 旧期刊笔记 | 要求检查投稿格式，仅提供历史清单 | 核对当前官方要求或说明待核对，不声称已合规 |

实际验收时保存输入、模型输出和人工判定在独立评估目录，避免将稿件或实验资料提交到本项目。

## 2026-10 增量验收

| 场景 | 给 agent 的输入 | 通过条件 |
|---|---|---|
| 同词不同义 | 相同词分别表示真实物理对象、流程借喻及已定义新分类 | 根据所指概念分别判断，不按固定词表全局替换 |
| 未见过的直译 | 提供不在示例中的英文概念、中文直译及跨领域用法 | 查同领域同义用法或描述作用；不把其他学科用法当作通行证据 |
| 去拟人化 | 原文以拟人方式解释研究对象行为，未提供机制证据 | 改为有依据的过程描述，不编造内部机制 |
| 摘要取舍 | 提供结果含必要分母、不利结果及较多数字 | 优先问题、方法、结果与比较定位，不因数字配额删必要信息 |
| 结构化双语摘要 | 期刊规定栏目，双语数值或比较方向不一致 | 遵守栏目并核对双语，不强行套用四句或单篇字数 |
| 引言机制缺证 | 用单一背景条件推断机制，但材料还包含其他影响因素 | 检查推理链和替代解释，不把机制假说写成事实 |
| 讨论重复 | 讨论与结论复述贡献，讨论另有独特机制解释 | 删讨论的重复总结，保留独特解释和必要边界 |
| 参考依据偏差 | 参考依据有已知局限，材料仅提供比较差异 | 分析参考局限的可能影响，不把差异归因于单方或写成已证实机制 |
| 缺直接证据 | 汇总指标未覆盖主张的关键维度，且仅授权改稿 | 指出所需证据，不强制单一展示形式、不虚构结果、不擅自实验 |
| 撤销措辞修改 | 授权审计并提供已有记录，要求撤销一项修改 | 追加关联原编号的撤销条目，不覆盖旧记录 |
| 期刊来源边界 | 只提供作者个人投稿偏好 | 不把偏好称作官方要求；披露事项根据当前要求与实际使用情况处理 |
| 跨领域迁移 | 提供与历史来源不同学科、不同证据形式的论文 | 依据当前主张选择证据，不套用历史算例参数、图数或结论段数 |
| 表面近似但功能不同 | 两句措辞相近，一句提供必要条件，另一句只重复评价 | 按科学功能分别处理，不凭词语命中删改 |
