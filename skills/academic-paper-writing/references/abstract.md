# 摘要写作

## 用最短的完整论证说明工作

非结构化摘要优先按“读者能理解的问题 → 做了什么 → 关键发现及依据 → 相对于既有工作的具体区别”组织。先让读者理解研究需要，再引入方法名称；期刊规定结构化摘要时服从对应栏目，不机械套用顺序。

结果选取足以支持核心回答的关键证据，定量研究保留必要的数值、比较基线、统计口径和适用条件，其他研究保留对应的主要发现及依据；按论证需要取舍，不设数字配额。不能为凑数补造结果，也不能为少写数字删除影响解读的不利结果或分母。

末句优先写清比较对象与本工作的实际区别，不用“具有重要意义”等自我评价替代贡献。比较必须有材料支持；没有比较依据时准确陈述工作定位，不虚构优越性或首创性。

## 降低独立阅读的理解成本

需要长篇定义或借助引文才能理解的自造术语，优先改为作用描述。必要的领域通行术语可以保留，但摘要应能独立理解。通常不放公式和变量符号；期刊有明确要求时按其要求处理。压缩术语不能抹去决定结论含义的方法区别或适用条件。

中英文摘要逐句核对信息对应关系：研究对象、方法、数值、比较方向与结论强度一致，语言组织可符合各自表达习惯。长度按目标期刊当前要求检查，单篇稿件曾用的中文字数和英文词数不是通用限额。

证据取舍与语义保护的判断情境见 [示例](examples.md)。
