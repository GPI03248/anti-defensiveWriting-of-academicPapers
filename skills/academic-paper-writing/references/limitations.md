# 局限性与论断

结合 Kiterlin/anti-defensive-writing 的防御性写作处理原则与 COMPASS 的语义保护要求。来源见技能包的第三方说明。

## 分类之后再修改

| 类型 | 例子 | 处理 |
|---|---|---|
| 决定结论成立的条件 | 仅在给定温度区间建立的关系 | 随相关论断保留，避免扩大适用范围 |
| 研究设计中的必要信息 | 单中心招募、观察性设计、预先排除标准 | 在方法中清楚说明；讨论其解释影响 |
| 研究层面的一般局限 | 未评估跨地区迁移 | 适合在讨论末尾或独立局限小节集中说明 |
| 功能相同的重复声明 | 每个结果后再说一遍“样本有限” | 留下合适位置的完整说明，删除多余复述 |
| 无信息的自我评价 | “仍有很大提升空间” | 删除，或用已经提供的具体条件和结果改写 |
| 不利或非显著结果 | 某指标下降、区间跨零 | 保留数值和解释影响；不能用文体优化遮盖 |
| 假想审稿质疑 | 也许还应该测十种情形 | 放在作者侧建议；不能凭空生成论文局限 |

先问：删除这一处会不会改变读者对本句的理解？再问：同一项信息是否已经在合适位置说明？两者共同决定保留或合并，不能只按出现次数判断。

## 放置原则

一般局限通常集中在讨论或局限性小节。方法中的研究假设和关键设计条件不能统一移到末尾。摘要可以独立被阅读，因此必要的样本范围、观察性设计或实验条件可能需再次简短出现。

只有一个片段时，可以删除片段内无信息的重复；不能假定未提供的末尾章节已经承载了某项限制。无法确定时，保留必要信息并提出迁移建议。

## 改写原则

陈述做了什么、在哪些条件下得到了什么结果。若“可能”“提示”“相关”准确表达证据强度，就保留；若连续多个词仅重复弱化同一关系，压缩为一次准确限定。

发现结论超出证据时，调整结论本身。例如证据来自两个数据集，就写这两个数据集上的结果，不先写“普遍有效”再加一句“也存在局限”。

指标有取舍时并列报告。不要将一个指标下降概括成整个方法失败，也不要只留下有利指标。原因不明时无需编造解释。
