# 术语与中文表达

根据创建者的改稿清单及后续反馈提炼。学习表达选择的依据，不把某篇论文中的保留、删除或替换决定变成跨领域词表。

## 先确定概念，再选择表达

判断一个词在当前句中指什么：实际物理对象、算法或方法、流程动作、分类名称，还是修辞借喻。核对其定义、上下文和证据；同一个词指代不同对象时可以有不同处理。不能因为它在另一篇稿件中被否决，就在当前稿件中自动替换。

按以下依据决定操作：

| 判断依据 | 操作 |
|---|---|
| 含义准确，符合目标领域惯例，读者可理解 | 保留；不为制造变化而换词 |
| 非常规名称承载明确分类或方法区别，作者有意使用且定义清楚 | 判断定义是否足以消除歧义；可保留，并在作者侧记下用途与理由 |
| 所指概念有领域通行名称，现表达是生硬直译、口语或引起领域误解的借喻 | 改为同义的通行名称；没有合适名称时直接描述对象、动作或判据 |
| 表达只是自评、修辞或重复提示，删除后不损失事实、条件或逻辑关系 | 删除多余表达；若其中含有效信息，先拆开保留 |
| 候选改法改变概念、完成状态、证据强度或统计口径 | 不采用；保留必要含义，疑问放作者侧 |

“已定义”是判断依据之一，不是所有名称的豁免条件；“不是通行术语”也不意味着必须删除真正的新概念。需要区分有意命名与无必要的直译。用户要求逐字保留时遵守授权范围，将歧义作为作者侧建议。

## 英文概念译入中文时

先确认英文概念在原语境中的含义，再查目标领域中文文献如何表达同一概念。其他学科的译法不能直接证明它适用于当前领域。拟保留有争议的直译时，应能提供同领域、同义用法的文献依据；无法确认时，不声称该译法通行，可直接说明其作用，或在名称影响方法理解时标记待确认。

不要为“中文规范化”强译领域通行的英文术语，也不要把英文形式默认视为更专业。按目标读者和期刊要求选择中文、英文或双语形式，必要时首次解释，后续统一。

描述研究对象的行为时，区分可观察过程与对其内部机制的推测。用材料支持的条件、动作及结果代替无依据的拟人解释；不能为了改得更专业而把推测写成事实。

## 用上下文检验改法

例如，同一表达用于真实测量装置时可能是准确术语，用于软件状态检查时却可能引发误解；后者应按实际检查功能命名。描述程序完成执行的词，也不能换成表示科学验证成功的词。这些例子说明判断方法，不指定固定替换对。

计数为零、真实不利结果和统计口径必须保留；不能仅因语气绝对而弱化有依据的结果。空泛提示可以删去，影响结果解释的条件不能一并删去。

修改名称后核对正文、图表及中英文摘要中的同一概念，保持定义和缩写一致。中文主语、英文第一人称及作者语体按领域与期刊惯例处理，不作机械全篇替换。摘要要求见 [摘要写作](abstract.md) 与 [期刊适配](venue-adaptation.md)。
