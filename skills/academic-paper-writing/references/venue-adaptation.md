# 期刊适配与个人期刊笔记

## 使用方式

只在用户要求格式检查或明确目标期刊时使用。获取期刊当前官方作者指南和对应文章类型的模板，再核对题目、摘要、章节、图表、引用和声明要求。记录依据及版本在作者侧，不写进论文正文。

下表来自创建者此前改稿清单，**是历史个人笔记，本次整合未核验为当前官方规定**。不能直接用作其他期刊的通用要求。无法取得当前指南时，可按用户明确要求采用这些偏好，但不要声称已通过期刊合规检查。

## 《航空学报》：原清单中的待核对条目

| 项目 | 原清单记录 |
|---|---|
| 题目 | 中文不超过 20 字；不用自定义缩略词 |
| 摘要 | 中文不少于 200 字；第三人称；不以“本文”为主语；不含公式和变量；英文与中文对应 |
| 引言 | 不编节号；结尾介绍拟做工作，不写结论 |
| 结论 | 分点写结论，不重复背景和方法 |
| 图表标题与表格 | 中英文双题；三线表 |
| 图尺寸与样式 | 单栏宽度不超过 8 cm；坐标轴全框、刻度向内；图例无底色和边框 |
| 符号与单位 | 符合适用国标，具体标准需按当前指南确认 |

核对后按官方现行要求及用户指定文章类型执行。有例外时在作者侧说明依据，不能把单个案例的字数、图宽或人称偏好固定为所有论文的规则。
